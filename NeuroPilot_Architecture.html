Autonomous Triage Loop
The runtime decision cycle: the model picks the patient AND the test, every result re-scores the cohort, and every step lands in the audit trail. Cognition drives blood; the blood-informed score drives MRI; and so on.
NeuroPilot
Continuous loop while Autonomous Triage is ON
1
PICK
POST /workup/next
highest full-precision score whose tier still indicates a test — deterministic, auditable max() pick
2
GATE
Rule-engine gate
escalation matrix (stage × tier) decides WHICH test — never another ML layer
3
EXECUTE
Test runs, result lands
blood → MRI → PET · severity-coherent result ranges stand in for LIS/RIS feeds
4
RE-SCORE
Trained model re-runs
NaN slot becomes a measured value → score, tier, SHAP attribution update live · example 0.68 → 0.81, rank #12 → #2
5
STOP
Stop conditions
tier says no test indicated · Stage 4 complete · queue empty — the model never over-tests
6
AUDIT
Trail + live banner
append-only events with API timestamps · rank before/after logged · clinician sees every pick
SAFETY
Clinician override
engine can decline an escalation (409 with reason); clinician can force with override=true — logged as an explicit override event
SAFETY
No silent failures
declined escalations return the engine reason; queue drains visibly on the banner; every state change is an event
SAFETY
Priority comparison built in
2–6 patients ranked on an explicit ladder: full-precision score → 12-mo conversion probability → stage → stable ID
~1.4 s cadence between autonomous steps409 = engine decline with human-readable reason0.68 → 0.81 blood result moves rank #12 → #2 (live verification run)max(candidates, key=score) — the entire selection policy, in one line

Model Layer
Two XGBoost model families on one shared 10-feature stage-aware vector. Missing tests are never imputed or invented — missingness is a learned, informative state; the pipeline orders the right test to resolve it.
NeuroPilot
Shared feature space
SHARED INPUT
The 10-feature stage-aware vector
age · sex · education_years · mmse · mmse_change · ptau181 · abeta4240 · hippocampal_volume · amyloid_positive · tau_positive
Un-ordered tests stay NaN — XGBoost routes them down a learned default path; SHAP badges it model default. Measured-but-gappy values (OASIS SES/MMSE) are median-imputed inside the bundled sklearn pipeline — identical at train and serve time.
MODEL 1 · RISK SCORING
XGBoost classifier — who needs attention now
Severity-correlated labels · CDR excluded (label-leakage guard) · subject-level split · preprocessing bundled in the served artifact. Serves score, tier (0.4 / 0.7 thresholds), per-patient SHAP attribution, global importance and Risk Simulator re-scoring.
CV AUC0.842
Test AUC0.871
Accuracy0.750
RF fallback0.874
MODEL 2 · PROGRESSION FORECAST
XGBoost pair — where the patient is headed
Same 10 features, two heads: MMSE-Δ regressor (expected 12-month point change ± uncertainty band) + conversion classifier (probability of crossing into the next phase: CN→MCI, MCI→AD, AD→severe). Projected tier = the risk model re-scoring the future vector.

Δ R²0.679
